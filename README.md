# 医路研培 · 2027

上海、南京、杭州大学附属三甲医院的住院医师规培与临床医学博士招生信息站。

这是非官方信息整理项目，申请条件与时间以医院、院校最新原文为准。已核实、部分核实、持续关注分别标注。首批内容并非完整医院名录。

支持电脑/手机布局、城市与类型筛选、关键词搜索、公告详情、当前设备收藏、报名日历和链接分享。

## 免费发布

GitHub Pages 使用公开仓库，无需购买域名。发布目录为仓库根目录，必须包括 index.html、assets、favicon.svg、data.json 和 .nojekyll。将 Settings → Pages 的发布来源设为 Deploy from a branch，选择 main 和 /(root)，保存后等待部署完成。若默认分支名称不同，以实际分支为准。

发布后应实测页面和 data.json；微信内访问需要在设备上确认，不能以部署状态代替访问验证。
